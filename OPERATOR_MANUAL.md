## 6. Technical Maintenance, Backups & Deployment

### 6.1 One-Click Automated Backup
Before making major content or codebase updates, always execute the automated backup script from the terminal:
```bash
npm run backup
```
* **Location:** Archives the entire project (excluding `node_modules` and `.next`) into `../Backups/website_backup_YYYY-MM-DD_HHMMSS.zip`.
* **Pointer:** Updates `website_backup_latest.zip` for instant one-click disaster recovery.
* **Git Tag:** Automatically stamps a timestamped git tag (e.g. `backup-20261016-1800`).

### 6.2 Zero-Downtime Production Deployment
The live website is hosted on Vercel at `https://thearchitectureofreality.vercel.app` and linked directly to the GitHub repository.

To deploy any changes to production, execute:
```bash
git add .
git commit -m "feat(content): add new chapter and update operator protocols"
git push origin main
```
Vercel will automatically detect the push, run the Next.js production build, and promote the new version with zero downtime.

To deploy directly via the command line:
```bash
./node_modules/.bin/vercel --prod --yes
```
